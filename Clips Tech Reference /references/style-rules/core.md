# Style rules — apply before writing any titles, headlines, or descriptions

Adapted from stop-slop by Hardik Pandya (MIT — see THIRD-PARTY-NOTICES.md).
This file is the complete rule set for clip copy — apply it as written.

## Core rules

1. **Cut filler phrases.** No throat-clearing openers, no emphasis
   crutches, no adverbs.
2. **Break formulaic structures.** No binary contrasts ("not X, it's Y"),
   no negative listings, no dramatic fragmentation, no rhetorical setups,
   no false agency.
3. **Use active voice.** Every sentence needs a human subject doing
   something. No passive constructions. No inanimate objects performing
   human actions ("the complaint becomes a fix").
4. **Be specific.** No vague declaratives ("The reasons are structural").
   Name the specific thing. No lazy extremes ("every," "always," "never")
   doing vague work.
5. **Put the reader in the room.** "You" beats "People." Specifics beat
   abstractions.
6. **Vary rhythm.** Mix sentence lengths. Two items beat three. End
   paragraphs differently. No em dashes.
7. **Trust readers.** State facts directly. Skip softening, justification,
   hand-holding.
8. **Cut quotables.** If it sounds like a pull-quote, rewrite it.

## Quick checks before delivering copy

- Any adverbs? Kill them.
- Any passive voice? Find the actor, make them the subject.
- Inanimate thing doing a human verb ("the decision emerges")? Name the
  person.
- Any "here's what/this/that" throat-clearing? Cut to the point.
- Any "not X, it's Y" contrasts? State Y directly.
- Titles/descriptions: does every line earn its place for a stranger
  scrolling at speed?

## Clip-copy bans

Never in a title, headline, or description:
- Throat-clearing openers: "here's the thing", "let me tell you", "what
  if I told you", "in today's video", "it turns out".
- Emphasis crutches and adverbs: really, actually, literally, truly,
  incredibly, honestly, just.
- "Not X, it's Y" contrasts.
- Rhetorical-question setups ("what if...?", "think about it").
- False agency: an inanimate thing doing a human verb ("the data tells
  us"). Name the person.
- Em dashes.
- Vague extremes doing vague work (every, always, never, nobody).
- Pull-quote lines. If it reads like a poster, rewrite it plain.
