PERFECT CLIPS — what's in this folder (LONG-FORM RUN)
=====================================================

This package was generated by the perfect-clips skill in LONG-FORM mode: it
found the complete stories inside a long recording, cut them frame-perfectly,
removed the dead weight from inside each one, and burned one-word captions
along the bottom. The picture itself is untouched — same resolution, same
aspect ratio, same framing as the source. Only the cuts changed.

THE CLIPS
  The numbered MP4s are the product, ranked best-first. The number after
  "LONG" is the score out of 100 (hook / engagement / value / shareability,
  25 each). Each one is a whole segment — a story, an argument, a bit — with
  a beginning, a middle and a payoff, not a moment.

  These are built for a landing page, not a swipe feed: widescreen, no
  on-screen headline, no music bed, captions parked low and still. The
  caption line sits high enough to clear YouTube's player controls.

  Fewer clips than you expected is a real answer, not a shortfall. An hour of
  material usually holds three or four genuine stories. The rest of the good
  stuff is short-form material — the REVIVE sheet says which.

TITLES + DESCRIPTIONS.txt
  Ready-to-paste titles and per-platform descriptions for every clip.

REVIVE - candidates.csv
  Every candidate considered — kept AND skipped — with scores and reasons.
  The "mode" column says whether a row was cut as a short or as long-form.
  Want a skipped one? Ask to "revive" it by number and it renders without
  redoing analysis.

clip data\
  The machine files: per-clip cut data (JSON), caption word timings, SRT
  captions, and a Premiere/Resolve XML per clip. The SRT uploads straight to
  YouTube as a caption track. Import the XML to re-edit any clip on the
  original footage with the cuts already placed.

If this folder also holds a large "source - ..." video, the run started
from a link: that's the downloaded VOD the clips were cut from, kept here
so the timeline XMLs keep working.

The MP4s are standalone forever. The XMLs reference the ORIGINAL source
video — if that file moves or is renamed, re-link it in your editor.
