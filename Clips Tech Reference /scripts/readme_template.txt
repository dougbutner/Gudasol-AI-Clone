PERFECT CLIPS — what's in this folder
=====================================

This package was generated by the perfect-clips skill: it found the most
clip-worthy moments in a long recording, cut them frame-perfectly, reframed
them vertical, and burned one-word captions plus a short on-screen headline
over the first seconds of each clip (the hook, in the clip's own words).

THE CLIPS
  The numbered MP4s are the product, ranked best-first. The number after
  "CLIP" is the virality score out of 100 (hook / engagement / value /
  shareability, 25 each). Post from the top down.

  Some clips open with a TEASER: a hook line pulled from inside the clip,
  played first, then the full moment plays through — you'll hear that line
  again where it naturally lands. That's intentional (it's a loop-close;
  viewers stay to see it arrive in context).

TITLES + DESCRIPTIONS.txt
  Ready-to-paste titles and per-platform descriptions for every clip,
  plus the on-screen headline each clip carries.

REVIVE - candidates.csv
  Every candidate considered — kept AND skipped — with scores and reasons.
  Want a skipped one? Ask to "revive" it by number and it renders without
  redoing analysis.

clip data\
  The machine files: per-clip cut data (JSON), caption word timings, SRT
  captions, and a Premiere/Resolve XML per clip. Import the XML to re-edit
  any clip on the original footage with the cuts already placed.

Some clips may carry a quiet music bed mixed low under the voice — that's
the optional music layer doing its job; the words always win.

If this folder also holds a large "source - ..." video, the run started
from a link: that's the downloaded stream VOD the clips were cut from,
kept here so the timeline XMLs keep working.

The MP4s are standalone forever. The XMLs reference the ORIGINAL source
video — if that file moves or is renamed, re-link it in your editor.
