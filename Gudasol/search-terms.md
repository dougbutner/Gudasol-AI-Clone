# Gudasol search terms

The niche-clips skill and `tools/ceo.py` read this file before any search.
Terms do not live in the skill. This project posts to the Gudasol YouTube
channel via `Gudasol/.env`, not Aquarius Academy’s credentials.

- Lane: talks and clips for the Gudasol / Easy Token channel.
- On lane: gudasol, easy, tetra, douglas

## Terms

- `gudasol`
- `easy token`
- `tetra earth`
- `douglas butner`

## Expansion rules

- Add a term only when a post found with a related phrase has a read, and its likes/views beat the niche median after at least 4 reads exist. Write the date and the counts under ## Added.
- Retire a term after 3 searches in a row that returned nothing on lane. Move it to ## Retired with the date and the miss count.
- Never add a term that another niche’s `search-terms.md` already owns.
- Never replace the lane.
